## X.1 库存盘点的作用

库存盘点是对仓库中物资进行清点核对的功能模块。通过盘点可以发现库存差异（盘盈/盘亏），并在审核通过后据此调整库存，确保**账实相符**。

模块位于"出入库管理"系统左侧导航中，与**入库管理、出库管理、库存管理、配置**并列。进入路径：**出入库管理 → 盘点任务**。

### 盘点类型

系统支持两种盘点类型：

| 类型 | 含义 |
|------|------|
| 全盘 | 对仓库物资进行全量盘点，并按**盘点结果全量覆盖**库存：盘到有则增、盘到无则减 |
| 抽盘 | 对部分物资进行抽查盘点，仅**更新被抽盘的物资**，未抽盘物资的库存不受影响 |

### 基本概念

| 概念 | 说明 |
|------|------|
| 账面数量 / 账面金额 | 系统中记录的库存数量及其金额 |
| 盘点数量 / 盘点金额 | 实际盘点录入的数量及其金额（盘点金额 = 盘点数量 × 成本价） |
| 盈亏数量 / 盈亏金额 | 盘点与账面的差异（盘盈为正、盘亏为负） |
| 成本价 | 物资的单位成本，用于计算金额（取自物资管理） |
| 是否盲盘 | 盲盘模式下执行盘点时不显示系统账面库存，避免盘点受账面影响 |
| 盘点状态 | 盘点任务的进度状态：未开始、盘点中、已完成、审批中 |
| 审批状态 | 盘点结果的审批进度，如已通过 |

差异计算规则：

```
盈亏数量 = 盘点数量 − 账面数量
盈亏金额 = 盈亏数量 × 成本价
```

> 示例：某物资成本价 5000、账面数量 0、盘点数量 10，则盘点金额 = 50000，盈亏数量 = 10，盈亏金额 = 50000（盘盈）。

### 操作权限概览

| 角色 | 创建盘点 | 执行盘点 | 审核 |
|------|:-------:|:-------:|:-------:|
| 普通用户 | ❌ | ❌ | ❌ |
| 库管 | ✅ | ✅ | ✅ |
| 管理员 | ✅ | ✅ | ✅ |

> 普通用户无盘点相关操作权限。若你无法看到或点击盘点操作按钮，请确认当前账号角色。

## X.2 盘点任务查询（列表与筛选）

盘点任务列表以**盘点任务**为单位展示，每行汇总一个盘点单的账面、盘点及盈亏数据。

### 列表字段

| 列名 | 说明 |
|------|------|
| 盘点单号 | 盘点任务编号，如 `PD20260710000002` |
| 盘点名称 | 盘点任务名称，如"0710全盘" |
| 仓库编码 / 仓库名称 | 盘点所属仓库 |
| 盘点类型 | 全盘 / 抽盘 |
| 是否盲盘 | 是 / 否 |
| 账面数量 / 账面金额 | 该任务下物资的账面合计 |
| 盘点数量 / 盘点金额 | 实际盘点录入的合计 |
| 盈亏数量 / 盈亏金额 | 差异合计（盘盈为正、盘亏为负） |
| 盘点状态 | 未开始 / 盘点中 / 已完成 / 审批中 |
| 审批状态 | 审批进度，如已通过 |
| 创建人 / 创建时间 | 任务创建人及创建时间 |
| 操作 | 去盘点、盘点完成、发起审批、生成库存、盘点详情、编辑、删除 |

### 操作步骤

1. 在顶部筛选区设置条件：**盘点单号、盘点名称、仓库、盘点类型、是否盲盘、创建时间**。
2. 点击 **查询** 过滤列表；点击 **重置** 清空条件。
3. 列表上方提供 **新增**（创建盘点任务）、**刷新**、**列设置** 按钮。

> **截图占位符：筛选查询区**
>
> `![盘点筛选查询](./images/stocktake-filter.png)`
>
> _图注：按盘点单号、名称、仓库、类型、是否盲盘、创建时间筛选。_

### 盘点状态与操作按钮可用性（重要）

每行操作按钮是否可点击，取决于当前**盘点状态**，其流转规则如下：

| 盘点状态 | 可点击的操作 | 不可点击的操作 | 状态流转说明 |
|---------|-------------|---------------|-------------|
| 未开始 | 去盘点、盘点完成、生成库存、盘点详情、编辑、删除 | 发起审批 | 点击"去盘点"后转为"盘点中" |
| 盘点中 | 去盘点、盘点完成、盘点详情 | 发起审批、生成库存、编辑、删除 | 点击"盘点完成"后转为"已完成" |
| 已完成（未审批） | 去盘点、盘点完成、发起审批、盘点详情 | 生成库存、编辑、删除 | 点击"去盘点"回退到"盘点中"；点击"发起审批"转为"审批中" |
| 审批中 | 盘点详情 | 其余全部 | 审批通过后转为"已完成（已审批）" |
| 已完成（已审批通过） | 盘点详情 | 其余全部 | 流程结束 |

> **注意事项：**
> - "发起审批"仅在盘点状态为"已完成（未审批）"时可用。
> - "生成库存"仅在盘点状态为"未开始"时可用（用途见 X.4）。
> - 已进入"审批中"或"审批通过"的任务不可再编辑/删除/重新盘点，仅能查看盘点详情。

## X.3 新增盘点任务

**操作步骤：**

1. 在盘点任务列表上方点击 **新增**。
2. 在弹窗中填写：
   - **盘点名称**（必填）
   - **仓库**（必填，下拉选择）
   - **盘点类型**（必填，全盘 / 抽盘）
   - **是否盲盘**（必填，是 / 否）
3. 点击 **确定** 提交。创建成功后系统提示"盘点任务创建成功"，任务出现在列表中，盘点状态为**未开始**。

> **截图占位符：新增盘点任务**
>
> `![新增盘点任务](./images/stocktake-create.png)`
>
> _图注：新建盘点任务弹窗，填写盘点名称、仓库、盘点类型、是否盲盘。_

### 注意事项

- **盘点任务必须选择仓库**，未选择无法提交。
- **盘点类型必须选择**（全盘 / 抽盘）。
- **同一仓库同时只能有一个进行中的盘点任务**，请先完成或结束已有任务再创建。
- 盲盘模式（是否盲盘 = 是）下，执行盘点时不显示系统账面库存（详见 X.5）。

## X.4 生成库存（生成盘点底表）

"生成库存"用于在**开始盘点前**快速生成盘点底表：点击后，系统会把**当前仓库所有在库物资**各生成一条记录，铺入"去盘点"的明细页面，便于逐项录入盘点数量，无需手动逐个添加物资。

**操作步骤：**

1. 在盘点状态为**未开始**的任务行点击 **生成库存**。
2. 系统将当前仓库的全部在库物资生成为盘点明细底表。
3. 随后进入"去盘点"页面即可看到已铺好的物资明细，逐项录入盘点数量。

### 注意事项

- **生成库存仅在盘点状态为"未开始"时可用**；一旦进入盘点中/已完成/审批中即不可再点击。
- 生成库存是盘点前的**预置明细**动作，**不会调整库存**；真正的库存调整发生在审核通过之后（见 X.7）。
- 若不使用"生成库存"，也可在"去盘点"页面通过"物资选择"手动添加待盘物资（见 X.5）。

## X.5 执行盘点（去盘点）

"去盘点"用于录入实际盘点结果。进入后为盘点明细页，可添加待盘物资并录入盘点数量，系统自动计算差异。

**操作步骤：**

1. 在盘点状态为**未开始**或**盘点中**的任务行点击 **去盘点**（首次点击后盘点状态变为**盘点中**）。
2. 进入盘点明细页，页面顶部显示盘点单号、盘点名称、仓库名称（只读），可按物资名称/物资编码筛选。
3. 添加待盘物资：
   - 点击 **物资选择**，在弹窗中按物资编码/名称查询，选择物资后点击 **确定**，该物资加入明细列表。
   - （若已用"生成库存"预置底表，则明细已铺好，可跳过此步。）
4. 录入盘点数量：点击某物资明细行的 **编辑**，在弹窗中填写 **成本价** 与 **盘点数量**；**盘点金额、盈亏数量、盈亏金额由系统自动计算**，点击 **确定** 保存。
5. 逐项录入完成后返回任务列表，进行"盘点完成"（见 X.6）。

**盘点明细字段：** 盘点单号、盘点名称、仓库名称、仓库编码、物资编码、物资名称、成本价、账面数量、账面金额、盘点数量、盘点金额、盈亏数量、盈亏金额、创建人、创建时间、操作（编辑 / 删除）。

### 注意事项

- **盲盘模式下不显示系统账面库存**（账面数量/金额显示为空或隐藏），以避免盘点受账面数据影响。
- **差异自动计算**：盈亏数量 = 盘点数量 − 账面数量；盘盈金额 = 盘盈数量 × 成本价；盘亏金额 = 盘亏数量 × 成本价。
- **成本价取自物资管理**，用于计算盘点金额与盈亏金额。
- 全盘按盘点结果全量覆盖（有就增、无就减）；抽盘仅更新被抽盘的物资。

## X.6 盘点完成

录入完成后，需将盘点任务标记为完成，系统据此汇总各物资的盘点与盈亏合计。

**操作步骤：**

1. 在盘点状态为**盘点中**（或**已完成**需再次修改）的任务行点击 **盘点完成**。
2. 盘点状态变为**已完成**，任务行的账面数量/金额、盘点数量/金额、盈亏数量/金额显示为该任务下所有物资的合计。

> **截图占位符：盘点完成后的汇总**
>
> `![盘点完成汇总](./images/stocktake-complete.png)`
>
> _图注：盘点完成后，任务行汇总展示盘点数量/金额及盈亏数量/金额。_

### 注意事项

- 盘点完成后仍可点击 **去盘点** 回退到"盘点中"继续修改，直到发起审批为止。
- 盘点完成后**不可**再点击生成库存、编辑、删除。
- 确认盘点数据无误后，再进行"发起审批"（见 X.7）。

## X.7 发起审批（盘点审核）

盘点结果需经审批，审批通过后系统据盈亏差异自动调整库存。

**操作步骤：**

1. 在盘点状态为**已完成（未审批）**的任务行点击 **发起审批**。
2. 在 **审批流程** 弹窗中：查看 **试算编号**（可复制），确认 **发起人**，选择 **审批人**（按"1 人依次审批"等规则）。
3. 点击 **确定** 提交，系统提示"盘点结果已提交审核"，盘点状态变为**审批中**，此时仅能查看盘点详情。
4. 审批通过后，盘点状态变为**已完成（已审批通过）**，系统提示"盘点审核通过，库存已调整"。

> **截图占位符：发起审批**
>
> `![发起审批](./images/stocktake-approval.png)`
>
> _图注：审批流程弹窗，含试算编号、发起人、审批人。_

### 注意事项

- **审核通过后自动调整库存**：盘盈增加库存、盘亏扣减库存，调整结果体现在**库存管理**模块。
- 全盘按盘点结果全量覆盖库存；抽盘仅调整被抽盘物资的库存。
- 盘点记录会**保存盘点人与盘点/创建时间**，便于追溯。
- 进入"审批中"或"审批通过"后，任务不可再编辑、删除或重新盘点。
