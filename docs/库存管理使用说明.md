## 2. 功能概述

库存管理模块用于**实时展示各仓库的物资库存情况**，包括可用数量、冻结数量、库存流水等信息，帮助库管人员掌握物资的实时状态并进行必要的库存操作。

### 核心功能

| 序号 | 功能 | 说明 |
|------|------|------|
| 1 | 库存列表 | 查看所有物资的当前库存 |
| 2 | 筛选查询 | 按仓库、物资分类、物资名称/编码筛选 |
| 3 | 库存调整 | 手动调整库存数量 |
| 4 | 库存冻结 | 冻结部分库存（预留） |
| 5 | 库存流水 | 查看物资的出入库流水记录 |

## 3. 基本概念

在使用库存管理模块前，请先理解以下核心概念，它们直接影响库存的展示与操作：

| 概念 | 说明 |
|------|------|
| 库存数量 | 物资在仓库中的总数量 |
| 冻结数量 | 已锁定、不能使用的数量 |
| 可用数量 | 库存数量 − 冻结数量，可用于出库的数量 |

其数量关系遵循以下公式：

```
库存数量 = 可用数量 + 冻结数量
可用数量 = 库存数量 − 冻结数量
```

> **提示：** 同一物资在不同仓库中是**分别独立统计**的。例如"螺丝钉"在 A 仓和 B 仓会各自显示一条库存记录，互不影响。

## 4. 权限说明

不同角色在库存管理模块中拥有的操作权限如下：

| 角色 | 查看库存 | 库存调整 | 库存冻结/解冻 |
|------|:-------:|:-------:|:-------:|
| 普通用户 | ✅ | ❌ | ❌ |
| 库管 | ✅ | ✅ | ✅ |
| 管理员 | ✅ | ✅ | ✅ |

> **说明：**
> - 普通用户仅能查看库存信息，看不到（或无法点击）"调整""冻结"等操作按钮。
> - 库管与管理员可执行全部操作。若你无法看到相关按钮，请确认当前账号角色。

## 5. 操作指南

### 5.1 进入库存管理

1. 登录系统后，在左侧导航菜单中依次选择 **库存管理 → 当前库存**。
2. 系统进入库存列表页，默认展示所有仓库、所有物资的当前库存。

> `![进入库存管理](./images/inventory-entry.png)`
>
> _图注：左侧导航菜单中的"库存管理"入口。_

### 5.2 查看库存列表

库存列表以**仓库维度**展示各物资的库存情况，每行代表"某仓库中某物资"的一条库存记录，通常包含以下信息：

- 仓库名称
- 物资分类
- 物资编码 / 名称
- 库存数量
- 冻结数量
- 可用数量
- 操作（调整、冻结、查看流水等）

> **截图占位符：库存列表**
>
> `![库存列表](./images/inventory-list.png)`
>
> _图注：库存列表页，展示各仓库物资的库存数量、冻结数量、可用数量。_

**阅读要点：**
- 每一行的"可用数量"应等于"库存数量 − 冻结数量"。
- 同一物资若存在于多个仓库，会显示为多行，请结合"仓库名称"列区分。

---

### 5.3 筛选查询

当库存记录较多时，可使用页面上方的筛选区快速定位目标物资。

**操作步骤：**

1. 在筛选区选择或输入筛选条件：
   - **仓库**：选择指定仓库（如不选则为全部仓库）。
   - **物资分类**：按分类过滤。
   - **物资名称 / 编码**：输入关键字进行模糊或精确匹配。
2. 点击 **查询**，列表将只展示符合条件的库存记录。
3. 如需重新查看全部，点击 **重置** 清空筛选条件。

> **截图占位符：筛选查询**

> _图注：按仓库、物资分类、物资名称/编码进行筛选查询。_

### 5.4 库存调整

当实际库存与系统记录不一致（如损耗、录入误差等）时，库管或管理员可手动调整库存数量。

**操作步骤：**

1. 在库存列表中找到目标物资，点击该行的 **调整** 按钮。
2. 在弹出的调整窗口中填写：
   - **调整后数量**（或调整增减值）。
   - **调整原因**（必填）。
3. 点击 **确定** 提交。
4. 提交成功后，系统提示"库存调整成功"，列表数量同步更新，并生成一条调整记录。

> **截图占位符：库存调整窗口**
>
> `![库存调整](./images/inventory-adjust.png)`
>
> _图注：库存调整弹窗，需填写调整数量与调整原因。_

**注意事项：**

- **调整原因为必填项**，未填写将提示"请填写调整原因"（E-03）。
- **调整后库存不能为负数**，否则提示"调整后库存不能为负"（E-01）。
- 每次调整都会**生成调整记录**，可追溯操作历史。
- 若调整涉及金额，**可能需要经过审批**流程后才生效，请留意审批状态。

### 5.5 库存冻结与解冻

冻结用于将部分库存"锁定预留"，冻结后的数量不可用于出库；解冻后恢复为可用。

#### 冻结库存

1. 在库存列表中找到目标物资，点击 **冻结** 按钮。
2. 输入 **冻结数量**。
3. 点击 **确定** 提交。
4. 提交成功后，系统提示"库存冻结成功"，该物资的冻结数量增加、可用数量相应减少。

> **截图占位符：库存冻结**
>
> `![库存冻结](./images/inventory-freeze.png)`
>
> _图注：库存冻结弹窗，输入需要冻结的数量。_

#### 解冻库存

1. 在库存列表中找到已冻结的物资，点击 **解冻** 按钮。
2. 确认解冻数量后提交。
3. 提交成功后，系统提示"库存解冻成功"，冻结数量减少、可用数量恢复。

> **截图占位符：库存解冻**
>
> `![库存解冻](./images/inventory-unfreeze.png)`
>
> _图注：库存解冻操作，解除后恢复为可用数量。_

**注意事项：**

- **冻结数量不能大于可用数量**，否则提示"冻结数量不能超过可用数量"（E-02）。
- 冻结后**可用数量随之减少**，但库存总数量不变。
- 冻结可随时**解除**，解除后对应数量恢复为可用。

---

### 5.6 查看库存流水

库存流水记录了物资的每一次出入库及调整变动，便于对账与追溯。

**操作步骤：**

1. 在库存列表中找到目标物资，点击 **流水** / **库存流水** 按钮。
2. 系统展示该物资的流水记录，通常包含：变动时间、变动类型（入库 / 出库 / 调整 / 冻结 / 解冻）、变动数量、变动后库存、操作人、关联单据等。
3. 可按时间或变动类型进一步筛选查看。

> **截图占位符：库存流水**

> `![库存流水](./images/inventory-transactions.png)`
>
> _图注：库存流水记录，展示物资的出入库及调整明细。_

## 6. 业务规则（验收标准）

以下为库存管理模块必须满足的业务规则，供使用与验收参考。

### 6.1 库存展示

| 规则编号 | 规则描述 |
|---------|---------|
| AC-01 | 库存数量 = 可用数量 + 冻结数量 |
| AC-02 | 可用数量 = 库存数量 − 冻结数量 |
| AC-03 | 库存按仓库维度展示 |
| AC-04 | 同一物资在不同仓库分别显示 |

### 6.2 库存调整

| 规则编号 | 规则描述 |
|---------|---------|
| AC-05 | 库存调整需要填写调整原因 |
| AC-06 | 库存调整后生成调整记录 |
| AC-07 | 调整后库存不能为负数 |
| AC-08 | 库存调整需要审批（如涉及金额） |

### 6.3 库存冻结

| 规则编号 | 规则描述 |
|---------|---------|
| AC-09 | 冻结数量不能大于可用数量 |
| AC-10 | 冻结后可用数量相应减少 |
| AC-11 | 冻结可以解除，解除后恢复可用 |

## 7. 系统提示与报错处理

### 7.1 成功提示

| 提示编号 | 场景 | 提示内容 | 级别 |
|---------|------|---------|------|
| T-01 | 调整成功 | 库存调整成功 | 成功 |
| T-02 | 冻结成功 | 库存冻结成功 | 成功 |
| T-03 | 解冻成功 | 库存解冻成功 | 成功 |

### 7.2 错误提示与解决方案

| 错误编号 | 场景 | 错误内容 | 解决方案 |
|---------|------|---------|---------|
| E-01 | 调整失败 | 调整后库存不能为负 | 减小调整数量，确保调整后库存 ≥ 0 |
| E-02 | 冻结失败 | 冻结数量不能超过可用数量 | 减少冻结数量，使其不超过当前可用数量 |
| E-03 | 调整失败 | 请填写调整原因 | 在调整窗口中补充填写调整原因 |

## 8. 模块关联与依赖

库存数据会受到其他业务模块操作的影响，理解这些关联有助于排查库存变动来源：

| 关联模块 | 对库存的影响 |
|---------|-------------|
| 入库管理 | 入库审批通过后**增加**库存 |
| 出库管理 | 出库审批通过后**扣减**库存 |
| 库存盘点 | 盘点结果**调整**库存 |
| 借用管理 | 借用时**冻结**库存，归还时**解冻** |

> **提示：** 若发现库存数量发生变化但未在本模块手动操作，可通过"库存流水"（见 5.6）查看关联单据，定位是哪个模块引起的变动。

## 9. 常见问题（FAQ）

**Q1：为什么我看不到"调整""冻结"按钮？**
A：这些操作仅对"库管"和"管理员"角色开放。普通用户只能查看库存。请确认当前账号角色。

**Q2：可用数量为什么比库存数量少？**
A：因为部分库存被冻结（预留）了。可用数量 = 库存数量 − 冻结数量。查看"冻结数量"列即可了解被锁定的部分。

**Q3：同一个物资为什么出现了多行？**
A：库存按仓库维度独立统计，同一物资存在于多个仓库时会分行显示，请结合"仓库名称"列区分。

**Q4：调整库存时提示"调整后库存不能为负"怎么办？**
A：说明本次调整会使库存低于 0。请减小调整（扣减）数量，确保调整后库存不小于 0。

**Q5：冻结时提示"冻结数量不能超过可用数量"怎么办？**
A：冻结数量最多只能等于当前可用数量。请减少冻结数量后重试。

**Q6：库存突然发生了变化，但我没有操作，怎么排查？**
A：库存可能因入库、出库、盘点、借用等关联模块的操作而变动。请通过"库存流水"查看变动明细及关联单据。
