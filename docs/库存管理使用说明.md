## X.1 库存管理的作用

库存管理模块用于**实时展示各仓库的物资库存情况**，并支持对库存进行冻结、解冻、调整以及流水追溯，帮助库管人员随时掌握物资的实时状态并完成日常库存操作。

模块位于"出入库管理"系统左侧导航中，与**入库管理、出库管理、盘点任务、配置**并列。进入路径：**出入库管理 → 库存管理**。

### 基本概念

理解以下概念有助于正确使用本模块：

| 概念 | 说明 |
|------|------|
| 库存数量 | 物资在仓库中的总数量 |
| 冻结数量 | 已锁定、不能使用的数量 |
| 可用数量 | 库存数量 − 冻结数量，可用于出库的数量 |
| 库存调整状态 | 物资当前是否处于调整流程中（如"调整中"表示调整申请正在审批） |

数量关系遵循以下公式：

```
库存数量 = 可用数量 + 冻结数量
可用数量 = 库存数量 − 冻结数量
```

### 操作权限概览

| 角色 | 查看库存/流水 | 库存调整 | 库存冻结 / 解冻 |
|------|:-------:|:-------:|:-------:|
| 普通用户 | ✅ | ❌ | ❌ |
| 库管 | ✅ | ✅ | ✅ |
| 管理员 | ✅ | ✅ | ✅ |

> 普通用户仅能查看库存与流水信息，看不到（或无法点击）调整、冻结、解冻等操作按钮。若你无法看到相关按钮，请确认当前账号角色。

## X.2 库存查询（列表与筛选）

库存列表以**仓库维度**展示库存，每行代表"某仓库中某物资"的一条库存记录。

### 列表字段

| 列名 | 说明 |
|------|------|
| 物资ID | 物资编码，如 `WZBM000014` |
| 物资名称 | 物资名称，如"文件夹" |
| 物资分类 | 所属分类，如"日常办公用品" |
| 仓库ID | 仓库编码，如 `CKBM000003` |
| 仓库 | 仓库名称，如"仓库3" |
| 库存数量 | 物资在该仓库的总数量 |
| 冻结数量 | 已锁定不可用的数量 |
| 可用数量 | 库存数量 − 冻结数量 |
| 单位 | 计量单位，如个 / 张 / 台 |
| 库存调整状态 | 是否处于调整流程中（如"调整中"） |
| 操作 | 每行的功能按钮（详见后续各节） |

### 操作步骤

1. 在顶部筛选区设置查询条件：
   - **仓库**（下拉选择，不选则为全部）
   - **物资分类**（下拉选择）
   - **物资ID**（文本输入）
   - **物资名称**（文本输入）
2. 点击 **查询**，列表仅展示符合条件的记录；点击 **重置** 清空条件并恢复全部数据。
3. 列表上方提供 **刷新**（重新加载最新数据）与 **列设置**（自定义显示/隐藏列）两个工具按钮。

> **截图占位符：筛选查询区**
>
> `![筛选查询](./images/inventory-filter.png)`
>
> _图注：按仓库、物资分类、物资ID、物资名称进行筛选查询。_

### 注意事项

- 库存**按仓库维度展示**，同一物资若存在于多个仓库，会分行显示，请结合"仓库ID / 仓库"列区分。
- 每行"可用数量"应等于"库存数量 − 冻结数量"。
- 当冻结数量大于库存数量时，可用数量可能显示为**负数**（如库存 5、冻结 6、可用 −1），此为异常情况，需通过库存调整或核对流水进行修正。

## X.4 库存冻结

冻结用于将部分库存"锁定预留"，冻结后的数量不可用于出库。

### 操作步骤

1. 在目标物资行点击 **库存冻结**。
2. 在弹窗中确认：**仓库、库存数量、已冻结数量、可用数量**。
3. 在 **新增冻结数量**（必填）中输入需要冻结的数量。
4. 点击 **确定** 提交。成功后系统提示"库存冻结成功"。

> **截图占位符：库存冻结弹窗**
>
> `![库存冻结](./images/inventory-freeze.png)`
>
> _图注：库存冻结弹窗，展示仓库/库存/已冻结/可用数量，并填写新增冻结数量。_

### 注意事项

- **新增冻结数量不能超过可用数量**，否则提示"冻结数量不能超过可用数量"，请减少冻结数量后重试。
- 冻结成功后，冻结数量增加、**可用数量相应减少**，但库存总数量不变。

---

## X.5 库存解冻

解冻用于解除此前的冻结，解冻后对应数量恢复为可用。

### 操作步骤

1. 在目标物资行点击 **库存解冻**。
2. 在弹窗中确认：**仓库、库存数量、已冻结数量、可用数量**。
3. 在 **计划解冻数量**（必填）中输入需要解冻的数量（输入框支持上下微调）。
4. 点击 **确定** 提交。成功后系统提示"库存解冻成功"，冻结数量减少、可用数量恢复。

> **截图占位符：库存解冻弹窗**
>
> `![库存解冻](./images/inventory-unfreeze.png)`
>
> _图注：库存解冻弹窗，填写计划解冻数量。_

### 注意事项

- 解冻可随时进行，解除后对应数量恢复为可用。
- **隐藏校验：当前仓库该物资若正处于出库审批中，则不允许库存解冻**——需等待出库审批流程结束后再操作，以避免与在途出库产生库存冲突。

## X.6 库存调整

当实际库存与系统记录不一致（如损耗、录入误差等）时，可手动调整库存数量。

### 操作步骤

1. 在目标物资行点击 **库存调整**。
2. 在调整弹窗中查看物资信息（**销售价、单位**等），并填写：
   - **调整后库存数量**（必填）：调整后该物资的库存总数。
   - **库存调整原因**（必填）：如"测试""盘点误差修正"等。
   - **调整人**（必填）：本次调整的经办人。
3. 点击 **确定**。
4. 若调整涉及金额，系统弹出 **审批流程** 窗口：
   - 显示 **试算编号**（可复制）；
   - 确认 **发起人**；
   - 选择 **审批人**（必填，点击"+"添加，可从"推荐审批人"中选择）；
   - 点击 **确定** 提交审批。
5. 提交后，该物资"库存调整状态"变为 **调整中**，需等待审批通过后调整才最终生效。

### 注意事项

- **库存调整原因为必填项**，未填写将提示"请填写调整原因"。
- **调整后库存不能为负数**，否则提示"调整后库存不能为负"，请减小调整数量。
- 每次调整都会**生成调整记录**（见 X.7），可追溯并查看审批状态。
- 涉及金额的调整**需经审批**，审批通过后方生效，期间"库存调整状态"为"调整中"。
- **隐藏校验（一）：当前仓库该物资若正处于出库审批中，则不允许库存调整**——需等待出库审批流程结束后再发起，以避免库存与在途出库冲突。
- **隐藏校验（二）：正处于"调整中"（库存调整审批未完成）的物资，不允许二次发起调整**——请等待当前调整审批完成后再进行下一次调整。

## X.7 查看流水与记录

库存变动可通过入库流水、出库流水及库存调整记录进行追溯与对账。

### 入库流水

在目标物资行点击 **入库流水**，弹出入库流水列表。

**列表字段：** 订单编号、业务类型（如采购入库 / 生产入库）、仓库ID、供应商ID、物资明细（可"查看详情"）、总金额、申请人、入库时间、状态（如"已通过"）。列表底部支持分页。

> **截图占位符：入库流水**
>
> `![入库流水](./images/inventory-in-transactions.png)`
>
> _图注：入库流水弹窗，展示该物资历次入库记录。_

### 出库流水

在目标物资行点击 **出库流水**，弹出出库流水列表。

**列表字段：** 出库单号、业务类型、物资明细、总金额、领用人、申请人、出库日期、状态。若无出库记录，则显示"暂无数据"。

> **截图占位符：出库流水**
>
> `![出库流水](./images/inventory-out-transactions.png)`
>
> _图注：出库流水弹窗，展示该物资历次出库记录（无记录时显示暂无数据）。_

### 库存调整记录

在目标物资行点击 **库存调整记录**，弹出调整记录列表。

**列表字段：** 物资ID、物资名称、仓库、物资分类、库存数量、冻结数量、调整后库存数量、调整人、审批状态（如"审批中"）、创建时间、操作（可"查看详情"）。列表底部支持分页。

> **截图占位符：库存调整记录**
>
> `![库存调整记录](./images/inventory-adjust-records.png)`
>
> _图注：库存调整记录弹窗，展示调整前后数量、调整人及审批状态。_

### 注意事项

- 库存数据会受其他模块影响：**入库管理**审批通过后增加库存、**出库管理**审批通过后扣减库存、**盘点任务**盘点结果调整库存、**借用管理**借用时冻结、归还时解冻。
- 若发现库存数量变化但未在本模块手动操作，可通过入库流水、出库流水、库存调整记录查看明细及关联单据，定位变动来源。
