## 2. 功能概述

库存管理模块用于**实时展示各仓库的物资库存情况**，包括库存数量、冻结数量、可用数量、库存调整状态及出入库流水等信息，帮助库管人员掌握物资实时状态并进行必要的库存操作。

模块位于"出入库管理"系统左侧导航中，与**入库管理、出库管理、盘点任务、配置**并列。

### 核心功能

| 序号 | 功能 | 说明 |
|------|------|------|
| 1 | 库存列表 | 以仓库维度查看所有物资的当前库存 |
| 2 | 筛选查询 | 按仓库、物资分类、物资 ID、物资名称筛选 |
| 3 | 库存调整 | 手动调整库存数量，涉及金额时进入审批流程 |
| 4 | 库存冻结 / 解冻 | 冻结部分库存（预留），并可解除冻结 |
| 5 | 入库 / 出库流水 | 查看物资的入库、出库流水记录 |
| 6 | 库存调整记录 | 查看物资历次调整记录及审批状态 |

## 3. 基本概念

在使用本模块前，请先理解以下核心概念，它们直接影响库存的展示与操作：

| 概念 | 说明 |
|------|------|
| 库存数量 | 物资在仓库中的总数量 |
| 冻结数量 | 已锁定、不能使用的数量 |
| 可用数量 | 库存数量 − 冻结数量，可用于出库的数量 |
| 库存调整状态 | 物资当前是否处于调整流程中（如"调整中"表示调整申请正在审批） |

数量关系遵循以下公式：

```
库存数量 = 可用数量 + 冻结数量
可用数量 = 库存数量 − 冻结数量
```

> **提示：** 同一物资在不同仓库中**分别独立统计**，会显示为多行，请结合"仓库ID / 仓库"列区分。

## 4. 权限说明

不同角色在库存管理模块中拥有的操作权限如下：

| 角色 | 查看库存 | 库存调整 | 库存冻结/解冻 |
|------|:-------:|:-------:|:-------:|
| 普通用户 | ✅ | ❌ | ❌ |
| 库管 | ✅ | ✅ | ✅ |
| 管理员 | ✅ | ✅ | ✅ |

> **说明：** 普通用户仅能查看库存与流水信息，无法执行调整、冻结、解冻操作。若你无法看到相关操作按钮，请确认当前账号角色。

## 5. 界面说明

### 5.1 页面布局

库存管理页面由三部分组成：

1. **左侧导航菜单**：入库管理、出库管理、**库存管理**（当前页）、盘点任务、配置。
2. **顶部筛选查询区**：用于按条件过滤库存记录。
3. **库存列表区**：以表格展示库存数据，右侧为每行的操作按钮；列表上方有"刷新"和"列设置"工具按钮。

> 页面右下角提供"任务管理"悬浮入口。

### 5.2 筛选查询区

筛选区提供以下条件，用于快速定位目标物资：

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 仓库 | 下拉选择 | 选择指定仓库，不选则为全部 |
| 物资分类 | 下拉选择 | 按物资分类过滤 |
| 物资ID | 文本输入 | 按物资编码查询 |
| 物资名称 | 文本输入 | 按物资名称查询 |

- 点击 **查询** 按条件过滤列表；
- 点击 **重置** 清空全部筛选条件，恢复展示全部数据。

> **截图占位符：筛选查询区**
>
> `![筛选查询](./images/inventory-filter.png)`
>
> _图注：按仓库、物资分类、物资ID、物资名称进行筛选查询。_

### 5.3 库存列表

列表以**仓库维度**展示库存，每行代表"某仓库中某物资"的一条库存记录，包含下列字段：

| 列名 | 说明 |
|------|------|
| 物资ID | 物资编码，如 `WZBM000014` |
| 物资名称 | 物资名称，如"文件夹" |
| 物资分类 | 所属分类，如"日常办公用品" |
| 仓库ID | 仓库编码，如 `CKBM000003` |
| 仓库 | 仓库名称，如"仓库3" |
| 库存数量 | 物资在该仓库的总数量 |
| 冻结数量 | 已锁定不可用的数量 |
| 可用数量 | 库存数量 − 冻结数量 |
| 单位 | 计量单位，如个 / 张 / 台 |
| 库存调整状态 | 是否处于调整流程中（如"调整中"） |
| 操作 | 每行的功能按钮（见第 6 节） |

**列表工具按钮：**
- **刷新**：重新加载最新库存数据。
- **列设置**：自定义显示/隐藏表格列。

**每行操作按钮：** 查看详情、库存解冻、库存冻结、库存调整、入库流水、出库流水、库存调整记录。

> **提示：** 当冻结数量大于库存数量时，可用数量可能显示为负数（如某物资库存 5、冻结 6、可用 −1），此为异常情况，需通过库存调整或核对流水进行修正。

### 6.2 库存冻结

冻结用于将部分库存"锁定预留"，冻结后的数量不可用于出库。

**操作步骤：**

1. 在目标物资行点击 **库存冻结**。
2. 在弹窗中确认以下信息：**仓库、库存数量、已冻结数量、可用数量**。
3. 在 **新增冻结数量**（必填）中输入需要冻结的数量。
4. 点击 **确定** 提交。成功后系统提示"库存冻结成功"，该物资冻结数量增加、可用数量相应减少。

> **截图占位符：库存冻结弹窗**
>
> `![库存冻结](./images/inventory-freeze.png)`
>
> _图注：库存冻结弹窗，展示仓库/库存/已冻结/可用数量，并填写新增冻结数量。_

**注意事项：** 新增冻结数量不能超过可用数量，否则提示"冻结数量不能超过可用数量"（E-02）。

---

### 6.3 库存解冻

解冻用于解除此前的冻结，解冻后对应数量恢复为可用。

**操作步骤：**

1. 在目标物资行点击 **库存解冻**。
2. 在弹窗中确认：**仓库、库存数量、已冻结数量、可用数量**。
3. 在 **计划解冻数量**（必填）中输入需要解冻的数量（输入框支持上下微调）。
4. 点击 **确定** 提交。成功后系统提示"库存解冻成功"，冻结数量减少、可用数量恢复。

> **截图占位符：库存解冻弹窗**

> `![库存解冻](./images/inventory-unfreeze.png)`

> _图注：库存解冻弹窗，填写计划解冻数量。_

### 6.4 库存调整（含审批流程）

当实际库存与系统记录不一致（如损耗、录入误差等）时，可手动调整库存数量。

**操作步骤：**

1. 在目标物资行点击 **库存调整**。
2. 在调整弹窗中查看物资信息（**销售价、单位**等），并填写：
   - **调整后库存数量**（必填）：调整后该物资的库存总数。
   - **库存调整原因**（必填）：如"测试""盘点误差修正"等。
   - **调整人**（必填）：本次调整的经办人。
3. 点击 **确定**。
4. 若调整涉及金额，系统弹出 **审批流程** 窗口：
   - 显示 **试算编号**（可复制）；
   - 确认 **发起人**；
   - 选择 **审批人**（必填，点击"+"添加，可从"推荐审批人"中选择）；
   - 点击 **确定** 提交审批。
5. 提交后，该物资"库存调整状态"变为 **调整中**，需等待审批通过后调整才最终生效。

> `![库存调整](./images/inventory-adjust.png)`
>
> _图注：库存调整弹窗，填写调整后库存数量、库存调整原因、调整人。_

> **截图占位符：调整审批流程**
>
> `![库存调整审批流程](./images/inventory-adjust-approval.png)`
>
> _图注：提交调整后弹出的审批流程窗口，需选择审批人。_

> **截图占位符：调整中状态**

> `![调整中状态](./images/inventory-adjusting-status.png)`

**注意事项：**

- **调整原因为必填项**，未填写将提示"请填写调整原因"（E-03）。
- **调整后库存不能为负数**，否则提示"调整后库存不能为负"（E-01）。
- 每次调整都会**生成调整记录**（见 6.7），可追溯并查看审批状态。
- 涉及金额的调整**需经审批**，审批通过后方生效，期间状态为"调整中"。

## 7. 业务规则（验收标准）

以下为库存管理模块必须满足的业务规则，供使用与验收参考。

### 7.1 库存展示

| 规则编号 | 规则描述 |
|---------|---------|
| AC-01 | 库存数量 = 可用数量 + 冻结数量 |
| AC-02 | 可用数量 = 库存数量 − 冻结数量 |
| AC-03 | 库存按仓库维度展示 |
| AC-04 | 同一物资在不同仓库分别显示 |

### 7.2 库存调整

| 规则编号 | 规则描述 |
|---------|---------|
| AC-05 | 库存调整需要填写调整原因 |
| AC-06 | 库存调整后生成调整记录 |
| AC-07 | 调整后库存不能为负数 |
| AC-08 | 库存调整需要审批（如涉及金额） |

### 7.3 库存冻结

| 规则编号 | 规则描述 |
|---------|---------|
| AC-09 | 冻结数量不能大于可用数量 |
| AC-10 | 冻结后可用数量相应减少 |
| AC-11 | 冻结可以解除，解除后恢复可用 |

## 8. 系统提示与报错处理

### 8.1 成功提示

| 提示编号 | 场景 | 提示内容 | 级别 |
|---------|------|---------|------|
| T-01 | 调整成功 | 库存调整成功 | 成功 |

### 8.2 错误提示与解决方案

| 错误编号 | 场景 | 错误内容 | 解决方案 |
|---------|------|---------|---------|
| E-01 | 调整失败 | 调整后库存不能为负 | 减小调整数量，确保调整后库存 ≥ 0 |
| E-02 | 冻结失败 | 冻结数量不能超过可用数量 | 减少冻结数量，使其不超过当前可用数量 |
| E-03 | 调整失败 | 请填写调整原因 | 在调整窗口中补充填写调整原因 |

## 9. 模块关联与依赖

库存数据会受到其他业务模块操作的影响，理解这些关联有助于排查库存变动来源：

| 关联模块 | 对库存的影响 |
|---------|-------------|
| 入库管理 | 入库审批通过后**增加**库存 |
| 出库管理 | 出库审批通过后**扣减**库存 |
| 库存盘点（盘点任务） | 盘点结果**调整**库存 |
| 借用管理 | 借用时**冻结**库存，归还时**解冻** |

> **提示：** 若发现库存数量变化但未在本模块手动操作，可通过"入库流水 / 出库流水 / 库存调整记录"查看关联单据，定位变动来源。

## 10. 常见问题（FAQ）

**Q1：为什么我看不到"库存调整""库存冻结"等按钮？**
A：这些操作仅对"库管"和"管理员"角色开放，普通用户只能查看库存与流水。请确认当前账号角色。

**Q2：可用数量为什么比库存数量少？**
A：因为部分库存被冻结（预留）了。可用数量 = 库存数量 − 冻结数量，可查看"冻结数量"列了解被锁定的部分。

**Q3：可用数量为什么显示负数？**
A：当冻结数量大于库存数量时会出现负的可用数量（如库存 5、冻结 6、可用 −1）。这属于异常数据，请核对入库/出库流水或通过库存调整进行修正。

**Q4：同一个物资为什么出现多行？**
A：库存按仓库维度独立统计，同一物资存在于多个仓库时分行显示，请结合"仓库ID / 仓库"列区分。

**Q5：提交库存调整后为什么状态是"调整中"，库存没变？**
A：涉及金额的调整需要审批。提交后进入审批流程，状态显示"调整中"，审批通过后调整才最终生效。可在"库存调整记录"中查看审批状态。

**Q6：调整时提示"调整后库存不能为负"或冻结时提示"冻结数量不能超过可用数量"怎么办？**
A：前者请减小调整数量确保结果 ≥ 0；后者请减少冻结数量使其不超过当前可用数量。

**Q7：调整时提示"请填写调整原因"怎么办？**
A："库存调整原因"为必填项，请在调整弹窗中补充填写后再提交。

**Q8：库存突然变化但我没操作，如何排查？**
A：库存可能因入库、出库、盘点、借用等关联模块操作而变动。请通过入库流水、出库流水、库存调整记录查看明细及关联单据。
